# Використання

## Запуск агента

1. Відкрийте чат Copilot у VS Code.
2. Виберіть тип сесії `Local`. У сесіях іншого типу prompt-команди (`/init`, `/check` та інші) не завантажуються.
3. Виберіть агента `build-engineer`.
4. Для повного послідовного запуску виконайте:

`/init`

Оркестратор послідовно запускає `/git-init`, `/create-project`, `/create-build`, `/create-actions` і `/check`. Після кожного етапу він виконує перевірки відповідного prompt-а та зупиняється при помилці.

## Окремі команди

Команди можна запускати окремо в чаті Copilot після вибору агента `build-engineer`:

- `/git-init` — перевірка Git і доповнення `.gitignore` записами `build/` та для тимчасових файлів IDE.
- `/create-project` — створення мінімального C++ Hello World-проєкту з назвою `hello`.
- `/create-build` — налаштування `add`, CMake, GoogleTest, CTest, `ci.sh` і `ci.bat`; передумова — `src/main.cpp`.
- `/create-actions` — створення або доповнення `.github/workflows/ci.yml`; передумови — `ci.sh` і `ci.bat`.
- `/check` — послідовна перевірка структури, складання, тестів, CI та Git.

Команди безпечні для повторного запуску в межах правил відповідних prompts. Вони не комітять зміни й не надсилають їх на GitHub.

## Локальна перевірка

Скрипти складання працюють із каталогом `build/`, конфігурують проєкт, збирають його та запускають CTest із виведенням помилок.

### Windows

У корені репозиторію виконайте:

```bat
ci.bat
```

### Linux і macOS

У корені репозиторію виконайте:

```sh
bash ci.sh
```

Успішним результатом є код завершення `0`, створений виконуваний файл `hello` на Linux/macOS або `hello.exe` на Windows, а також пройдений тест `BasicAddition`. Для багатоконфігураційного генератора виконуваний файл Windows може бути розташований у `build/Release/hello.exe`.

## Запуск зібраної програми

Після успішного складання запустіть програму з кореня репозиторію.

### Linux і macOS

```sh
./build/hello
```

### Windows

Для одноконфігураційного генератора:

```bat
build\hello.exe
```

Для багатоконфігураційного генератора:

```bat
build\Release\hello.exe
```

Очікуваний вивід:

```text
Hello, World!
```
